## ADDED Requirements

### 需求:差额拆解使用简洁的月度层级
系统必须按固定顺序展示“预算余额、消费超支、收入差额、资产变动”四组。预算余额必须只展示截至所选月的汇总值；消费超支、收入差额和资产变动必须同时展示截至所选月的总额和各月增量。系统禁止再单独展示“本月资产变动”，也禁止继续显示“预充暂存”“利息/其他”“新增差额”等旧名称。

#### 场景:展示月度差额拆解
- **当** 用户查看12月统计且有效账本从11月开始
- **那么** 系统必须在消费超支、收入差额和资产变动下分别列出11月与12月金额，并使各月金额之和与该组总额一致

#### 场景:某月资产变动不可计算
- **当** 相邻月份存在未填写的必要储蓄余额
- **那么** 系统必须在资产变动的对应月份显示无法计算，并允许显示一条简短缺失数据告警

### 需求:统计页移除长篇口径说明
系统必须删除月份选择器下方以及差额拆解、消费、储蓄和基金区域中的长篇口径说明；系统必须保留金额、明细、状态以及会影响数据完整性的短告警。

#### 场景:查看正常月份
- **当** 目标月数据完整且没有告警
- **那么** 统计页禁止显示账本范围、公式、基金内部移动、累计口径或历史补录等说明段落

#### 场景:存在缺失数据
- **当** 储蓄余额或基金市值明确留空
- **那么** 系统必须保留对应的简短数据不完整告警

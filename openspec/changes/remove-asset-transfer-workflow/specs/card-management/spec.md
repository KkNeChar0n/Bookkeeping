## 新增需求

### 需求:真实资产只通过余额和本金维护

系统必须把储蓄卡月度真实余额作为储蓄资产的唯一事实来源，并把带审计的基金本金校准作为基金成本基础的唯一人工修改入口；禁止通过通用资产划转自动修改余额或本金。

#### 场景:储蓄卡之间移动资金

- **当** 用户在现实中把资金从一张储蓄卡转到另一张储蓄卡
- **那么** 用户只需填写两张卡各自的真实月度余额，系统禁止要求额外创建通用资产划转记录

#### 场景:基金申购或赎回

- **当** 用户发生基金申购或赎回并修改基金本金
- **那么** 系统必须通过本金校准更新所选月份快照并保存审计日志，禁止要求选择来源储蓄卡

#### 场景:删除存在旧划转历史的卡片

- **当** 用户删除一张曾参与通用资产划转的卡片
- **那么** 系统必须只清理该卡自身及直接关联数据，禁止回退或修改仍保留卡片的余额、本金或基金快照

## 新增需求

### 需求:删除卡片清理资产划转与本金审计
系统删除储蓄卡或基金卡时，必须在同一原子事务内反向恢复仍保留卡片受到的已应用余额影响、删除该卡作为来源或目标的资产划转以及该卡的基金本金校准日志；如果删除来源储蓄卡但目标基金仍保留，必须同时回退由相关正常划转实际增加的基金本金。

#### 场景:删除划转来源储蓄卡
- **当** 用户删除一张曾正常划转到仍保留基金的储蓄卡
- **那么** 系统必须删除相关划转并减回对应基金本金，统计禁止继续包含这些划转

#### 场景:删除划转目标卡
- **当** 用户删除一张作为划转目标的储蓄卡或基金卡
- **那么** 系统必须恢复仍保留来源储蓄卡由正常划转扣减的余额、删除以该卡为目标的划转，且禁止留下孤儿记录

#### 场景:删除基金清理校准日志
- **当** 用户删除一只存在本金校准记录的基金
- **那么** 系统必须同步删除该基金的全部本金校准记录

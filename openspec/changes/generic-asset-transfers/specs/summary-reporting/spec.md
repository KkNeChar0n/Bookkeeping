## 新增需求

### 需求:对账单独展示基金投入
系统必须按统计截止月份累计所有储蓄卡到基金本金的资产划转，并作为“基金投入”单独展示；该金额必须包含正常划转和“本金已包含”的历史补录，禁止包含储蓄卡之间的划转。

#### 场景:按月份累计基金投入
- **当** 用户查看某一月份的统计
- **那么** 系统必须只累计划转日期月份不晚于该月份的储蓄到基金划转

#### 场景:储蓄卡间划转不计入基金投入
- **当** 统计期间存在储蓄卡到储蓄卡的划转
- **那么** 该划转金额禁止进入基金投入、收入或消费

### 需求:利息其他排除基金投入
系统计算“利息/其他”时必须把累计基金投入作为资产内部迁移从残差中剥离，使用 `利息/其他 = 差额 - 基金盈亏 - 收入差额 + 消费超支 + 预充暂存 + 基金投入`。

#### 场景:基金投入不再形成残差
- **当** 储蓄余额因投资减少且同额资金已通过资产划转进入基金本金
- **那么** 这笔基金投入必须显示在独立拆解项中，禁止继续形成等额的负“利息/其他”

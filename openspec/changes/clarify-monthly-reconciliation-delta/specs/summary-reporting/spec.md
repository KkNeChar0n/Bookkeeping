## 新增需求

### 需求:区分累计未解释差额与相邻月变化

统计必须将现有利息/其他明确标注为截至对账月份的累计未解释差额，并提供可展开的上月累计、本月累计和本月新增差额。新增差额必须为本月累计减上一自然月累计，使用整数分计算，禁止改变既有累计金额或把未解释差额直接等同于真实利息。

#### 场景:历史差额不继续增加
- **当** 九月和十月累计利息/其他均为 -1025.08 元
- **那么** 十月必须展示累计 -1025.08 元和新增 0.00 元，并允许查看九月累计

#### 场景:保留真实新增变化
- **当** 九月累计为 -1025.08 元而十月累计为 -1023.85 元
- **那么** 十月新增必须为 +1.23 元，禁止抹平九月累计差额

#### 场景:跨年月份和按年视图
- **当** 用户查看一月或按年统计
- **那么** 一月必须与上年十二月比较，按年模式中的月度新增必须明确标识为该年十二月新增而非全年新增

### 需求:新增差额数据完整性和来源透明

系统必须识别相邻两月的储蓄余额、基金净投入是否足够计算新增差额。必要数据缺失时必须显示无法计算及原因，禁止默认上月累计为零。余额沿用历史月份或基金净投入起点发生变化时必须提示数据来源及解释限制；基金市值未知不得单独阻断差额计算。

#### 场景:首次有余额的月份
- **当** 本月已有储蓄余额但上月没有可用储蓄余额
- **那么** 本月新增必须显示无法计算，禁止将本月累计直接作为新增

#### 场景:基金净投入缺失
- **当** 本月或上月存在尚未确认的基金净投入
- **那么** 新增差额必须显示无法计算并提示未完整对账

#### 场景:余额沿用与未知市值
- **当** 有必要余额及净投入但储蓄余额沿用旧月，或基金市值未知
- **那么** 沿用时必须提示来源月份，市值未知不得单独阻断差额，并必须说明新增仅反映已保存数据而非真实当月利息

#### 场景:全局期初调整与无校准标记
- **当** 用户修改全局期初或添加备注为历史校准的普通预算支出
- **那么** 系统必须使用实际保存的预算计算两月累计，不得把备注猜测为专属校准类型，不得修改真实余额或自动生成调平记录

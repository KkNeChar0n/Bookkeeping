## ADDED Requirements

### 需求:资产起账不截断累计消费范围
保留消费历史的手工起账模式必须按各月完整消费、定额与充值计算并持续累计，不因资产起账月份排除更早消费。累计超支必须逐月累加超出定额的部分。无累计标记的旧模式必须继续原消费范围，禁止静默转换。

#### 场景:同日旧消费和新消费
- **当** 起账当天已有消费100元，起账后同日新增消费20元
- **那么** 消费历史与本月额度计算的已花都必须为120元

#### 场景:历史定额充值与次月结转
- **当** 起账前各月已有定额、消费和充值，并形成结余
- **那么** 历史超支持续累计、结余参与真实消费资金分配；资产对账中的结转只计起账月之后，起账月及以前已计入手工期初的资金流不得重复计入

#### 场景:历史消费资金修正
- **当** 累计消费模式中修改历史定额或超额充值
- **那么** 必须允许更新消费统计，但仍禁止恢复或填写起账前的旧资产收入与余额

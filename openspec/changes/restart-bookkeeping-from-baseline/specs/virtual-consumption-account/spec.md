## ADDED Requirements

### 需求:历史消费查询与新账消费额度隔离
手工起账模式按本月划分消费范围：此前月份仅历史查询，禁止参与新账消费额度、超支、预充和结转；本月已保存及之后新增、补录消费必须正常计入，不能把本月早于确认时点的消费排除。

#### 场景:同日旧消费和新消费
- **当** 起账当天已有消费100元，起账后同日新增消费20元
- **那么** 消费历史与本月额度计算的已花都必须为120元

#### 场景:补录历史及次月结转
- **当** 起账后补录此前月份消费500元，并在新账留下100元预充
- **那么** 旧消费不得吞掉预充或使次月结转失真

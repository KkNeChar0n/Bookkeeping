## ADDED Requirements

### 需求:展示新账范围而不伪造历史资产对账
起账后，系统必须在预算、储蓄、基金、消费额度和对账展示中说明当前起点。起账前月份只能展示历史消费查询，禁止将已删除预算当成零预算而报告全部消费超支，禁止展示以新期初计算的过去资产余额。

#### 场景:查看起账前月份
- **当** 用户选择起账前月份
- **那么** 系统必须显示历史消费及分类，并提示旧资产账本已删除，不展示新账资产对账与超支数值

### 需求:新增差额不跨越起账边界
起账月的新增差额必须按用户新填写的期初与资产计算，禁止减去旧账上一月残差。手工新账尚未完整填写时不得宣称已核实或自动调平。

#### 场景:起账月利息
- **当** 起账时对账为0，起账后当月产生1元利息且其它输入完整
- **那么** 累计与起账后新增利息其他都必须为1元，并说明只统计起账之后

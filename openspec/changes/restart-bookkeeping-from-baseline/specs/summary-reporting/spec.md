## ADDED Requirements

### 需求:展示新账范围而不伪造历史资产对账
起账后，系统必须在预算、储蓄、基金和对账展示中说明资产新起点。消费历史累计模式必须展示历史每月消费、定额、充值与超支，提供截至所选月的累计消费资金统计；禁止因资产起点而截断消费累计，禁止展示以新期初计算的过去资产余额。旧无标记模式保持原展示。

#### 场景:查看起账前月份
- **当** 用户选择起账前月份
- **那么** 系统必须显示消费及分类、消费定额和超支，并提示旧资产账本已删除，不展示新账资产对账

### 需求:累计消费期初填写指引
累计消费模式必须明确手工期初合计为当前银行实际加截至起账月累计消费定额、累计超额充值和当前基金总额。起账月预算只记一次累计定额支出，不补旧资产流水，不重复扣真实余额，不把超额充值再记为预算支出。

#### 场景:含历史结转的累计起账
- **当** 三个月定额各20元，充值共20元、消费共69元，银行100元、基金60元，手工期初240元并在起账月预算记累计定额支出60元
- **那么** 实际为160元、预算180元、差额-20元、累计超支9元，历史结转不造成利息其他差额

### 需求:新增差额不跨越起账边界
起账月的新增差额必须按用户新填写的期初与资产计算，禁止减去旧账上一月残差。手工新账尚未完整填写时不得宣称已核实或自动调平。

#### 场景:起账月利息
- **当** 起账时对账为0，起账后当月产生1元利息且其它输入完整
- **那么** 累计与起账后新增利息其他都必须为1元，并说明只统计起账之后

## 上下文

应用同时维护储蓄月度真实余额、基金当前本金和当前市值。现有对账把“当前基金本金”加入每个月的预算总资产，导致每次内部注资都会抬高预算，再通过独立资产划转记录抵消；漏一笔记录就会产生等额“利息/其他”。同时基金只有当前最终市值，切换统计月份仍会使用同一个值。

## 目标 / 非目标

**目标：**

- 让储蓄转基金成为天然零和的内部资产移动，无需逐笔记录也不影响差额。
- 基金预算基线固定为创建时的 `initialBalance`，当前本金只承担成本基础职责。
- 保存每月最后一次基金本金和市值，让统计按截止月份取最近快照。
- 兼容现有数据库和备份，并为当前基金值建立迁移快照。

**非目标：**

- 不删除通用资产划转台账；它仍可作为资金路径备注，但不参与统计。
- 不自动猜测迁移前每个历史月份的基金本金或市值。
- 不改变储蓄预算、收入、消费超支和预充结转的既有口径。

## 决策

### 对账采用固定基金期初基线

预算和实际改为：

```text
预算总资产 = Σ储蓄预期余额 + Σ基金期初本金
实际总资产 = Σ储蓄实际余额 + Σ截止月份基金市值
基金盈亏   = Σ截止月份基金市值 - Σ截止月份基金本金
其他差额   = 总差额 - 基金盈亏 - 收入差额 + 消费超支 + 预充暂存
```

当前本金不再进入预算总资产，`fundInvestment` 不再进入公式。储蓄减少 T、基金市值和本金增加 T 时，实际总资产与基金盈亏都不变，因此差额不会依赖划转记录。

考虑过继续从本金校准日志或资产划转推导基金投入，但仍要求历史记录完整，无法解决用户的核心困扰，因此不采用。

### 新增按月基金快照

IndexedDB v19 新增 `fundMonthSnapshots`，每条记录包含基金、月份、本金、市值和更新时间，并对 `[fundCardId+month]` 建唯一索引。同月重复保存覆盖同一条记录，统计按不晚于目标月份的最近快照读取。

基金详情更新市值时携带月份并同时保存当时本金；本金校准以及仍保留的储蓄转基金操作也同步刷新当前月份快照。基金卡上的 `fundPrincipal`、`fundValue` 继续保存最新快照值，供基金首页快速展示。

目标月份没有任何快照时，以 `initialBalance` 同时作为本金和市值，并把基金数据标为未填写；统计显示不完整提示，禁止把当前值倒灌到历史月份。

### 迁移与备份

v19 升级把每只现有基金的当前本金、市值写入升级当月快照。备份提升为 v11 并导出 `fundMonthSnapshots`；导入 v1-v10 且没有新快照时，使用备份 `exportedAt` 所在月份为每只基金生成一条快照。导入 v11 时校验基金关联、月份和非负金额。

删除基金时原子删除其月度快照。恢复旧版代码时新表会被忽略，卡片上的最新本金和市值仍可读取。

### 统计界面按月份展示基金

统计页基金区域改为读取所选截止月份的快照，不再展示“当前值，不分时段”。差额拆解删除“基金投入”，并明确“其他差额”不含基金内部注资。

## 风险 / 权衡

- [迁移前历史月份缺少基金快照] → 回退期初值并提示未填写，不伪造历史数据；用户从本月起只需月末更新市值。
- [只改本金未同步市值会暂时形成盈亏变化] → 本金校准保存同月快照并继续提示用户市值来自基金 App；月末更新后自然校正。
- [旧资产划转仍会改变基金本金] → 同步当前月快照，但统计不读取划转金额，避免重新引入依赖。
- [用户编辑较早月份] → 快照按月保存，卡片当前值始终取最新月份，历史编辑不会覆盖较新的当前展示。

## 迁移计划

1. 发布 v19 数据库和 v11 备份支持，为现有基金生成当月快照。
2. 切换对账公式并移除基金投入展示。
3. 上线基金月份选择与快照历史列表。
4. 使用现有 2026-10 备份验证：基金本金增加不再要求补划转，其他差额只保留非基金残差。

## 新增需求

### 需求:基金更新关联统计月份

系统必须允许用户选择月份更新基金市值，并把该月最后一次本金和市值保存为月度快照；基金当前展示必须使用最新月份快照。

#### 场景:保存当前月份市值

- **当** 用户在基金详情选择当前月份并保存市值
- **那么** 系统必须更新当月快照和基金当前展示值

#### 场景:补录历史月份市值

- **当** 用户保存早于最新快照的历史月份市值
- **那么** 系统必须更新历史快照，且禁止覆盖基金最新月份的当前展示值

#### 场景:本金发生变化

- **当** 用户校准本金或系统通过保留的基金划转改变本金
- **那么** 系统必须同步更新操作月份快照中的本金，并保留该月已有市值

### 需求:删除基金清理月度快照

系统删除基金时必须在同一事务中清理该基金全部月度快照，禁止留下孤儿数据。

#### 场景:删除存在快照的基金

- **当** 用户删除一只存在多个历史快照的基金
- **那么** 系统必须删除基金及其全部月度快照

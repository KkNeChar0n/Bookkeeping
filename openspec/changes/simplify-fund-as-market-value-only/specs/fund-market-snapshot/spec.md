## ADDED Requirements

### 需求:基金仅保存月度当前市值
系统必须允许用户按月保存基金当前市值，并禁止要求基金预充、买入、赎回、净投入或历史流量起点。目标月没有记录时必须沿用不晚于目标月的最近市值；明确留空时必须标记市值未知。

#### 场景:保存基金市值
- **当** 用户为2026-11填写基金当前市值6000元
- **那么** 系统必须只保存该月市值，并禁止生成预充或净投入金额

#### 场景:沿用最近市值
- **当** 2026-11没有基金记录但2026-10保存了3000元
- **那么** 系统必须在11月展示沿用自10月的3000元及其来源月份

### 需求:旧基金现金字段只用于兼容迁移
系统必须允许导入旧备份中的预充、净投入、历史起点和固定基金基准，但禁止这些字段参与新预算、实际资产或差额计算。系统必须向用户提示旧预充应迁移到普通储蓄卡，且禁止自动创建卡片或复制金额。

#### 场景:导入旧预充快照
- **当** 旧备份的10月基金市值为3000元且预充为5000元
- **那么** 新统计必须只把3000元市值计入基金资产，并提示5000元旧预充尚待用户填入普通储蓄卡

#### 场景:重新保存旧月份
- **当** 用户重新保存含旧预充和净投入字段月份的基金市值
- **那么** 系统必须保留市值并移除该月废弃的基金现金流字段

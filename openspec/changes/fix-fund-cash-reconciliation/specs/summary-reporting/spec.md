## 修改需求

### 需求:预算 vs 实际汇总
系统必须提供总结视图：真实储蓄卡展示预算、实际和差额，基金作为月度汇总展示市值、独立预充现金、本月与累计净投入，不恢复基金卡或盈亏明细。消费侧必须作为唯一虚拟消费账户单独展示额度、已消费、剩余和超支，禁止把虚拟消费账户当作用户卡片参与真实卡片列表。

总资产对账预算基准必须为储蓄预期减累计基金净投入加基金市值，实际必须为储蓄实际加独立基金预充加市值。系统必须保留收入差额、消费超支、消费预充暂存和真实利息/其他残差，禁止强制抹平残差。缺少净投入必须提示暂不完整。

#### 场景:展示真实卡片汇总
- **当** 用户打开总结视图
- **那么** 系统必须按储蓄卡展示预算、实际与差额，并分别展示基金月度汇总及唯一虚拟消费账户

#### 场景:消费超支与剩余同时成立
- **当** 当前月已消费超过额度但尚未用完包含超额充值的可用资金
- **那么** 系统必须同时展示正的本月剩余和正的消费超支，禁止让超额充值隐藏超预算事实

#### 场景:基金买入与市值变动
- **当** 独立预充减少100元、基金市值增加110元、本月净投入增加100元
- **那么** 对账残差必须保持不变，禁止将10元市值涨幅计为利息

#### 场景:真实银行利息
- **当** 储蓄实际增加5元利息，其他预算与现金流不变
- **那么** 利息/其他必须增加5元，即使存在基金记录也禁止归零
